# Sample data

## `BTCUSD_1h_sample.csv`

720 hourly BTC/USD OHLCV bars (~30 days) used by the example backtest so it runs
out-of-the-box with **no network access**.

> **This is synthetic data, not real market history.** It is a seeded
> geometric-Brownian-motion price path generated by
> [`scripts/generate_sample_data.py`](../scripts/generate_sample_data.py), chosen
> so the repo is hermetic and reproducible. It is realistic in *shape* (valid
> OHLC ordering, plausible volatility) but carries no real price information, so
> backtest results on it are illustrative only.

Regenerate it deterministically with:

```bash
python scripts/generate_sample_data.py            # 720 bars, seed 42
python scripts/generate_sample_data.py --bars 2000 --seed 7
```

Columns: `timestamp` (UTC, ISO 8601), `open`, `high`, `low`, `close`, `volume`.

## Using real data

Fetch real BTC/USD history from an exchange with the optional `fetch` extra
(ccxt) and point the config's `data_path` at the result:

```bash
pip install -e ".[fetch]"
```

A CCXT-based fetch script lands with a later piece; the `HistoricCSVDataHandler`
already accepts any CSV with the columns above, real or synthetic.
